# HzSetter

Windows 托盘程序。图标显示主屏幕当前刷新率，菜单里可以切换每台显示器在当前分辨率下支持的刷新率。

## 用法

运行 `hzsetter.exe` 后，图标出现在任务栏通知区域。左键或右键打开菜单。

- 只有一台显示器时，菜单直接列出可选刷新率，当前项带勾。
- 多台显示器时，每台屏幕一个子菜单。主屏幕在最上面，其余按「屏幕 2」「屏幕 3」排列。
- 点选某一项即切换该显示器的刷新率，分辨率和色深保持不变。
- 再次启动时如果已经在运行，会提示「HzSetter 已在运行」，不会开第二个实例。
- 菜单底部可以退出。

图标上的数字是主屏幕刷新率。读不到有效刷新率时显示 `--`。鼠标悬停可以看到刷新率、分辨率，以及显示器名称（系统返回的是通用监视器名时不显示）。

## 图标颜色

相差不超过 2 Hz 才算靠近某个倍数。两边一样近时归到 30 的倍数。

| 颜色 | 条件 | 例子 |
| --- | --- | --- |
| 焦糖 | 更靠近 25 的倍数 | 24、25、48、49、50、75、100 |
| 石板蓝 | 更靠近 30 的倍数 | 30、59、60、90、120、180、240 |
| 灰绿 | 离两边都超过 2 Hz | 144、165 |
| 冷灰 | 没有读到刷新率 | |

## 构建

需要 64 位 Windows，以及 Rust 1.85 或更新版本（`edition = "2024"`）。

```powershell
cargo build --release
```

生成的程序在 `target\release\hzsetter.exe`。Release 配置使用最小体积优化、链接时优化，并去掉调试符号。

```powershell
cargo test
```

图标绘制在任何机器上都能测。显示器枚举和模式测试会读取本机正在使用的屏幕，并只做驱动测试（`CDS_TEST`），不会真的改刷新率。

## 行为说明

程序通过 `EnumDisplayDevices` / `EnumDisplaySettingsEx` 列出已经接到桌面的显示器，跳过镜像驱动。可选刷新率只包含当前分辨率、当前色深下、不低于 20 Hz 的模式。

切换时先用 `ChangeDisplaySettingsEx` 做测试，通过后再写入注册表并立即应用。驱动拒绝该模式时，菜单不改，并弹出错误说明。
